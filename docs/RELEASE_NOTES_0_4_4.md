# AGR Revit Bridge 0.4.4 — ранний доступ

- «Показать Revit» больше не раскрывает все служебные окна процесса. Показывается главное окно выбранного процесса и его уже видимый активный диалог. Невидимые окна .NET, уведомлений и GDI не раскрываются.
- Ошибки чтения списка, запуска импорта, выгрузки Revit и конвертации остаются в отчёте. Выбирается запись ошибки; подробности можно скопировать существующей кнопкой отчёта.
- Для ошибок активного задания сохраняется отдельный `blender_error_*.json` с этапом, версиями, ID запроса и стеком ошибки внутри папки задания. Токен сеанса и переменные окружения в него не записываются.

Эта версия исправляет показ окон и потерю диагностики. Конкретный сбой экспорта на компьютере с Revit 2026.4 по одним скриншотам не установлен: нужен текст ошибки/журнал с того компьютера. Полная выгрузка на Revit 2026 локально не проверялась.

Пустое главное окно Revit возможно при открытии документа через API: обычный вид модели не активируется. Процесс остаётся открытым для последующих операций. Это само по себе не доказывает сбой импорта.

Установка: «Получить версии» → «Ранний доступ» → 0.4.4 → «Установить».
Стабильная версия остаётся 0.4.0.
