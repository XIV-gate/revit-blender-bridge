# AGR Revit Bridge 0.4.5 — ранний доступ

- Одна кнопка «Экспорт логов» сохраняет ZIP с читаемой сводкой, версиями, настройками, ошибками и журналами.
- Время начала и длительность этапов: подготовка, запуск/открытие Revit, чтение каталога, выгрузка, конвертация, импорт. Паузы после готовности исключаются.
- Общая и доступная RAM, потребление и пик памяти Blender/Revit/конвертера; замеры RAM на переходах между этапами.
- Общая, занятая и свободная VRAM через драйвер NVIDIA в момент экспорта. Если счётчики недоступны, значение явно неизвестно.
- Экспорт доступен во время обработки, пока Blender отвечает. История этапов сохраняется в папке задания и доступна после перезапуска.
- RVT, геометрия, USD, текстуры, каталог и файл команды с токеном не включаются. Большие логи ограничены по объёму; усечения и пропуски перечисляются в отчёте.

Диагностический архив может содержать локальные пути и названия элементов: отправляйте его лично. Конкретная причина медленной или неудачной выгрузки на другом компьютере ещё не установлена; эта версия помогает собрать данные для её поиска.

Установка: «Получить версии» → «Ранний доступ» → 0.4.5 → «Установить».
Стабильная версия остаётся 0.4.0.

[Инструкция по логам](https://github.com/XIV-gate/revit-blender-bridge/blob/v0.4.5/docs/DIAGNOSTICS_RU.md).
