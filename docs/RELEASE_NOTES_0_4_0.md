# AGR Revit Bridge 0.4.0 — единая стабильная сборка

Все текущие возможности теперь доступны в стабильной версии:

- Редактируемые Mesh-инстансы: изменение одного меша обновляет связанные экземпляры прямо на фасаде.
- Быстрое изменение состава: локальное отключение и восстановление уже загруженных объектов; получение только новых элементов, когда состав допускает безопасное добавление.
- Проверенный кэш выгрузки и полная перевыгрузка при изменении исходника или неоднозначном составе.
- Категории, рабочие наборы, семейства/типы и отдельные объекты. Частичный выбор, причины исключения, ручное включение элементов до импорта.
- Читаемые имена объектов и Mesh, исправление старых служебных имён без повторного импорта.
- Независимое превью рамок у каждой строки слоя/типа/объекта: работает до импорта, независимо от галочек, несколько слоёв одновременно; повторная кнопка убирает только этот слой.
- Постоянно видимый ручной путь Revit.exe и выбор найденных установок 2024–2027, включая зарегистрированные нестандартные пути Windows.
- Объединённая информация об элементах без отдельной геометрии, доступ к исходным сообщениям и ID, подсказки кнопок.
- Исправленная установка ZIP и восстановление собственной регистрации Revit.

Исправления 0.4.1, 0.4.2 и далее выходят в раннем доступе. После их проверки
и доводки следующая стабильная версия — 0.5.0. Для обычной работы выбирайте
«Стабильные».

Нужны Windows и установленный активированный Revit. Оригинальный RVT не
перезаписывается. Для неподписанной DLL Revit может запросить доверие пользователя;
аддон не подтверждает диалог автоматически. Ручной путь доступен всегда,
незарегистрированные установки выбираются вручную.

Проверены Blender 4.2.14 и 5.2.3, обычные Python-тесты, шесть вариантов обработчика.
Полный импорт реальной модели ранее проверен на Revit 2027. Для 2024–2026 проверены
сборка с API соответствующего года и общая логика; полный импорт не запускался.
Связанные RVT и отсутствующие исходные текстуры остаются ограничениями.

Установка: `agr_revit_bridge-0.4.0.zip` через Blender → Preferences → Add-ons →
Install from Disk либо «Получить версии» → «Стабильные» → 0.4.0 → «Установить».
При уже заблокированном старом обновителе установите новый ZIP один раз вручную.
