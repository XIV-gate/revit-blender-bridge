# AGR Revit Bridge 0.5.0 — стабильная версия

Миниатюры материалов Revit (`thumbnail`) больше не считаются текстурами поверхности:
они не вызывают ложные сообщения о недостающих текстурах и не мешают объединению
подтверждённых нативных вариантов. Настоящие bitmap-ссылки, включая отсутствующие
файлы, по-прежнему требуют сохранения UV.

В стабильную ветку перенесены изменения серии 0.4.x: единое дерево категорий и
элементов, превью каждой строки, сгруппированные настройки подключения и импорта,
быстрое скрытие и восстановление уже загруженных элементов, редактируемые Mesh
с общими данными, перенос UV и доступных текстур, экспорт диагностических логов
со временем этапов и данными памяти, исправления отмены и подготовки рабочих копий.
Установочный пакет общий: отдельные версии для этих функций больше не нужны.

- Добавлены «Учитывать данные Revit» и «Допуск, мм» с начальным значением **0,1 мм**.
  Достоверные нативные варианты семейств дополняют сравнение самих сеток. Имена
  семейства и типа не заменяют проверку геометрии; изменённые, составные и
  текстурные случаи сохраняют консервативные ограничения.
- Изменение допуска применяется при обновлении импорта из пригодной сохранённой
  выгрузки без запуска Revit. Raw-варианты в кэше не удаляются: можно уменьшить
  допуск обратно. Пересборка может заменить ручные правки Mesh; перед подбором
  настроек сохраните отдельную копию сцены.
- Нативный ключ и локальные оси захватываются из реального корня geometry instance.
  Неоднозначный корень или изменённая геометрия не получают разрешения на нативное
  объединение. Материал с отсутствующей bitmap-картой не считается нетекстурным.
- Простые нетекстурные варианты одного семейства и типа дополнительно проверяются
  по поверхности. Разворот локальных осей на 180° компенсируется в размещении.
  На реальном наборе из 35 стульев допуск 5 мм объединяет две тесселяции в один
  Mesh; 0,1 мм сохраняет два. Уменьшение допуска возвращает исходное разделение.
  Текстурные, составные и неподтверждённые варианты этим способом не объединяются.

- Исправлено распознавание повторяющейся геометрии: арифметический шум около
  нуля больше не создаёт отдельный меш для каждого одинакового элемента. На
  проверенной модели 1562 размещения используют 669 прототипов вместо 979;
  53 одинаковых импоста используют общий меш. Различия размеров, материалов
  и UV продолжают учитываться. Правка ограничена float32-компонентами до 1e-9
  около нуля; позиции измеряются в метрах, нормали и UV безразмерны.
- Перенос текста рассчитывается по реальной ширине шрифта, панели и масштабу
  интерфейса. Исправлены статусы, пути и длинные сообщения в диалогах; короткие
  предлоги не остаются отдельно в конце строки. Обрезание статуса после восьми
  строк убрано.

- Постоянный загрузчик Revit включён в обычный ZIP аддона. Отдельно скачивать
  или устанавливать его не нужно. При первом подключении выберите в Revit
  «Всегда загружать». Обычные обновления меняют рабочий модуль, сохраняя файл
  загрузчика, его путь и регистрацию. Это проверено сменой рабочего модуля
  в настоящем Revit 2027 без повторного запроса DLL.
- Платного сертификата нет; сертификаты и параметры доверия Windows/Revit
  автоматически не меняются. Замена самого загрузчика, перенос установки или
  другой вариант Revit могут потребовать нового подтверждения.
- Ошибки запуска загрузчика отображаются в Blender и включаются в экспорт логов.
  Повреждённые и отсутствующие обязательные файлы останавливают запуск вместо
  незаметного перехода к старой схеме подключения.
- Кнопка закрытия простаивающего Revit теперь запрашивает штатный выход и ждёт
  завершения процесса. При отказе или тайм-ауте процесс остаётся открытым, причина
  показывается в Blender. Активная отмена по-прежнему может остановить обработчик.
- Причина ошибки Revit при открытии теперь сохраняется в отчёте: например,
  ошибки вставок модели больше не заменяются общим `Opening was canceled`.
  Автоматического удаления проблемных элементов или ремонта исходного RVT нет.
- Добавлены проверки отмены между этапами подготовки копии и понятное сообщение,
  если API не позволяет отключить внешнюю ссылку.

После обновления с 0.4.7 нажмите «Получить список» и подтвердите переподключение,
если аддон его предложит. Затем один раз разрешите постоянный загрузчик в Revit.
Для обновления достаточно штатного интерфейса аддона; ручная правка файлов не нужна.
Чтобы пересоздать инстансы уже импортированной модели, обновите импорт после
установки 0.5.0. Само обновление аддона не меняет геометрию открытой сцены.

Проверка временного вида прошла девять сценариев: обычный проект, проект с
управляющим шаблоном/скрывающим фильтром и общая модель, каждый на уровнях
coarse/medium/fine. Выбранная геометрия сохранялась; изменения видов откатывались.
Это проверка конкретных сценариев, а не гарантия открытия любого RVT.

Дополнительная рабочая модель при обновлении 2024 → 2027 дала ошибки дверных
вставок. Открытие безопасно остановлено. Сравнение с прямым открытием всех рабочих
наборов прервано; влияние способа открытия ещё не установлено. Специальные правки
геометрии этой модели не добавлены. Revit 2024–2026 проверены сборкой и тестами
логики; полные нативные прогоны в этих версиях пока не выполнены.

Установка: «Получить версии» → «Стабильные» → 0.5.0 → «Установить».


### Границы настройки инстансов

Нулевой допуск означает точное сравнение сохранённых сеток в fallback-режиме.
Подтверждённая нативная идентичность управляется отдельной галочкой. Увеличение
допуска не обещает объединение визуально похожих объектов с разной тесселяцией,
UV или подрезками. Разворот на 180° проверяется только вместе с поверхностью и
данными семейства; произвольные повороты и отражения по имени типа не подбираются.
Проверка публичных API и сборка шести обработчиков не являются полной нативной
проверкой всех семейств во всех версиях Revit.
