# AGR Revit Bridge 0.4.6 — ранний доступ

- Исправлена отмена с ошибкой `StructRNA of type Scene has been removed`.
- Фоновое задание хранит внутренний ID сцены и получает её заново, вместо долгого хранения недействительной RNA-ссылки. Переименование и Undo не ломают обращение к существующей сцене.
- Если исходная сцена удалена, обработчик останавливается. Новая сцена с тем же названием не получает чужой результат.
- Ошибка записи файла отмены не блокирует прямую остановку собственного процесса.

Ошибка со скриншота воспроизведена до исправления. Проверены удаление сцены, повторное использование имени, настоящий Undo, отмена из интерфейса и недоступный файл отмены в изолированных Blender 5.2.3 и 4.2.14. Revit I/O в этих проверках имитируется; конкретная причина сбоя выгрузки на удалённом компьютере не установлена.

Если старая версия уже оставила панель занятой после ошибки отмены, сохраните нужную сцену и перезапустите Blender, затем обновитесь. Признак занятости не сохраняется в `.blend`.

Установка: «Получить версии» → «Ранний доступ» → 0.4.6 → «Установить».
Стабильная версия остаётся 0.4.0.
