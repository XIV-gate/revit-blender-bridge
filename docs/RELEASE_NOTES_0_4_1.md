# AGR Revit Bridge 0.4.1 — ранний доступ

Настройки собраны в три понятных раздела внутри «Настроек»:

- **Подключение Revit**: автопоиск установок, ручной путь Revit.exe, подключение и закрытие рабочего процесса.
- **Настройки импорта**: инстансы, материалы, текстуры, упаковка изображений, координаты, детализация и полная перевыгрузка.
- **Рабочие данные**: рабочая папка, повторное использование проверенного кэша и его очистка.

Путь Revit.exe и кнопка автопоиска убраны из верхней части панели. Отдельное
поле каталога регистрации скрыто: регистрация определяется автоматически.
Сохранённые параметры импорта и внутренние настройки подключения остаются совместимыми.

Установка: «Получить версии» → «Ранний доступ» → 0.4.1 → «Установить» либо
ZIP `agr_revit_bridge-0.4.1.zip` через Install from Disk.

Это тестовая версия интерфейса. Последний стабильный релиз остаётся **0.4.0**;
следующая стабильная версия после проверки исправлений — **0.5.0**.
