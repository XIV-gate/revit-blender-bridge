# AGR Revit Bridge 0.5.2 — ранний доступ

Версия доступна в канале «Ранний доступ». Стабильная версия остаётся 0.5.0;
0.5.1 также опубликована и доступна для выбора в обновителе.

- Выбор способа импорта собран в один список с тремя режимами: «Отдельные объекты»,
  «Отдельные объекты-инстансы» и «Объединить по семействам». Первые два сохраняют
  отдельный объект для каждого элемента; третий уменьшает количество объектов.
- Объединение по семействам выполняется конвертером до загрузки в Blender.
  Геометрия собирается из выбранных элементов с их размещениями; это не запуск
  Join над тысячами уже созданных объектов Blender.
- Вершины не свариваются: соседние и пересекающиеся детали остаются отдельными
  участками сетки. Материалы, UV, нормали и зеркальные размещения сохраняются.
  Такой режим не заменяет очистку топологии и не делает модель единым замкнутым
  телом для печати или расчётов.
- Большая группа разбивается на части не более 1 000 000 треугольников каждая.
  Одному семейству поэтому может соответствовать несколько объектов Blender.
- Сохраняется происхождение геометрии: связь граней с исходными ID элементов
  позволяет работать с выбором исходных элементов в контексте объединённого
  объекта. Один объединённый объект не означает один исходный элемент Revit.
- Пригодная проверенная исходная выгрузка используется для смены способа импорта
  без нового открытия RVT. Исходный RVT и сохранённая сырая геометрия не меняются.
  При смене режима импортированная геометрия пересоздаётся; ручные правки Mesh
  могут быть заменены, поэтому перед пересборкой сохраните отдельную копию сцены.
- Убрано ненужное удлинение временных имён файлов при пересборке из глубокой
  папки кэша Windows; необязательный файл прогресса не прерывает конвертацию,
  если Windows кратковременно блокирует его во время чтения интерфейсом.

Шесть worker-вариантов собраны с версией 0.5.2.0. Изменена только версия сборок:
алгоритм нативной выгрузки Revit остаётся прежним. Постоянный загрузчик ABI 1
переиспользуется без пересборки.

## Проверка скорости

Замеры в изолированном Blender 5.2.3, начиная с готовой выгрузки:

| Сцена | Исходных элементов | Объектов после объединения | Конвертация USD | Импорт Blender |
|---|---:|---:|---:|---:|
| Синтетическая, 183 000 треугольников | 73 133 | 10 | 5,78 с | 0,46 с |
| Реальная выгрузка, 7 283 485 треугольников после фильтра | 26 400 | 88 | 24,65 с | 3,29 с |

Реальная выгрузка содержит 82 семейства; шесть дополнительных объектов появились
из-за ограничения размера части. Исходные файлы не менялись. Синтетический тест
повторён в Blender 4.2.14: 6,44 с конвертации и 0,66 с импорта.
В режиме отдельных инстансов синтетический тест остановлен внешним лимитом
180 секунд до завершения конвертации; время его импорта Blender не измерено.

Открытие RVT и нативная выгрузка Revit в эти времена не входят. Это замеры
конкретных сцен и компьютера, не обещание скорости любого RVT. Файл T1 размером
803 МБ локально не предоставлен и не проверен.

У объединения есть цена: повторяющаяся геометрия разворачивается, поэтому расход
RAM и размер USD могут увеличиться. До записи проверяются общий объём и оценка
памяти; при нехватке памяти используйте инстансы или уменьшите выбор.

Проверены три режима, смена режима из кэша, исключение/возврат элементов,
исходные ID граней, UV, материалы и нормали после зеркальных преобразований,
упакованные текстуры и выбор исходного элемента в Edit Mode в Blender 4.2/5.2.
Новый запуск Revit для этих изменений не заявляется: нативный код не менялся,
обновлена только версия шести скомпилированных обработчиков.
