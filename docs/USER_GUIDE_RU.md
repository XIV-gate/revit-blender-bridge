# AGR Revit Bridge 0.3.1 — ранний доступ

Локальный импорт выбранной геометрии RVT из панели Blender. Dynamo и Python
отдельно устанавливать не нужно. На компьютере должны быть Windows и установленный,
работающий Revit 2024–2027. Основная версия Blender — 5.2 LTS (проверено на 5.2.3).
Дополнительно проверена совместимость с Blender 4.2.14 LTS.
Файл более новой версии Revit открыть в старой версии Revit нельзя.

## Установка и первый запуск

1. В Blender откройте Preferences → Add-ons → меню → Install from Disk и выберите
   ZIP `agr_revit_bridge-0.3.0.zip` целиком. Включите AGR Revit Bridge.
2. В 3D View нажмите N, откройте вкладку AGR, панель AGR Revit Bridge.
3. Сохраните .blend в папку проекта, выберите RVT и нажмите «Получить список».
   Установленный Revit определяется автоматически. По умолчанию кэш находится
   рядом со сценой: Data/Cache/RevitBridge. Для несохранённой сцены можно явно
   указать каталог кэша в «Настройки». Revit.exe и путь кэша можно изменить там же.
4. При первом запуске окно автоматически покажет точный путь создаваемого файла
   регистрации `.addin`; подтвердите его создание. Этот шаг нужен один раз.
   Файл указывает на обработчик внутри установленного аддона: не перемещайте
   установленную папку после подключения. При удалении аддона удалите также
   именно этот файл регистрации. Собственное подключение этой установки, в том
   числе от версии 0.1.0, обновляется этой кнопкой. Чужая регистрация не заменяется.
5. Нажмите «Получить список». Запустится отдельный Revit, который прочитает копию.
   Первый запуск и обновление старого RVT могут занять несколько минут.

В Revit не требуется вручную создавать 3D-вид или граф Dynamo. Сам Revit всё равно
необходим: формат RVT обрабатывается через его API. При первом подключении Revit
может спросить о загрузке локального дополнения. Если требуется ответ на диалог,
панель сообщит об этом: нажмите «Показать Revit», проверьте вопрос и ответьте вручную.
Для неподписанной тестовой сборки «Загрузить один раз» действует только до выхода
из этого процесса Revit. Выбор «Всегда загружать» сохраняет ваше решение о доверии
дополнению; такую настройку пользователь выбирает сам, аддон её не изменяет.
Обычные предупреждения документа при открытии рабочей копии принимаются автоматически
и записываются в отчёт. Предупреждения API также сохраняются в отчёт без ручного
подтверждения. Ошибки не исправляются удалением элементов: обработчик пытается
безопасно откатить операцию и сообщает причину остановки. Неизвестные диалоги,
лицензирование и настройки приватности автоматически не подтверждаются.
Обычное окно обновления 2024 → 2027 — индикатор процесса.
Обновлённая рабочая модель не сохраняется поверх исходника и не синхронизируется.

## Обновление плагина

Внизу панели показана установленная версия. Нажмите «Получить версии».
Выберите канал «Стабильные» или «Ранний доступ», затем конкретную версию и
«Установить …». Ранний доступ содержит тестовые сборки с возможными ошибками;
они не предлагаются как стабильные. Можно явно выбрать предыдущую версию для
возврата назад. Подтверждение показывает тестовый статус и предупреждает о возврате.
Установленную версию повторно устанавливать нельзя. Плагин проверяет контрольные
суммы ZIP и файлов, а затем перезагружает свой код в текущем Blender.
Список содержит до 300 последних публикаций; черновики, неполные пакеты и теги
без числовой версии не предлагаются. Кнопка ничего не устанавливает автоматически.

При переходе с 0.2.0 на 0.3.0 один раз установите новый ZIP вручную:
старый проверяющий код 0.2.0 не принимает архивы с несколькими обработчиками Revit.
Начиная с 0.3.0 выбирать стабильные и тестовые версии можно внутри панели.

Проверка запускается только по вашей кнопке и учитывает разрешение Blender на
доступ в интернет. Авторизация GitHub для опубликованных публичных релизов не нужна.
При недоступности сети или отсутствии опубликованного релиза появляется сообщение;
текущая версия продолжает работать.

Обновление выполняется после окончания импорта. Собственная рабочая копия Revit
закрывается без сохранения; остальные процессы Revit плагин не закрывает. Старые
DLL сохраняются в отдельных каталогах, поэтому их блокировка Revit не мешает
следующим обновлениям. Настройки импорта, выбранные элементы и геометрия сцены
сохраняются. Если новая версия не загрузилась, код и подключение Revit откатываются.
Открытие другого `.blend` отменяет ещё не установленное обновление.

Для перехода с версии 0.1.0 один раз установите новый ZIP и нажмите «Подключить
Revit». Если разовой установке ZIP мешает занятая старая DLL, закройте использующий
её Revit и повторите установку. Встроенный обновитель версии 0.3.0 сохраняет старые
DLL и использует отдельные файлы для последующих версий.

## Выбор и повторный импорт

Список можно показать по категориям, рабочим наборам или отдельным объектам.
Число справа от группы — выбранные / все элементы. Галка группы меняет все её
элементы; частично выбранная группа показывает неполное число без общей галки.
Поиск фильтрует отображение, но не меняет выбор. Кнопки «Все», «Ничего» и
«Рекомендуемые» действуют на весь каталог, включая скрытые поиском строки.

Предварительно выбираются вероятные фасадные и спорные элементы. Мебель, инженерные
системы и явно внутренние элементы обычно исключены. Это подсказка, а не точное
геометрическое распознавание оболочки. В реальных проектах наружная стена может
быть помечена как внутренняя: проверьте рабочие наборы, спорные строки и причину
рекомендации в режиме «Объекты». Итоговый экспорт следует вашим галкам.

Нажмите «Импортировать выбранное». Измените галки и нажмите «Обновить импорт» для
замены предыдущего результата этого импорта. Новая ревизия сначала проверяется,
затем заменяет предыдущую. Посторонние объекты не удаляются; пользовательские
объекты внутри старой коллекции сохраняются. Изменения самой импортированной
геометрии при обновлении заменяются. Для ручного моделирования создавайте собственные
объекты в отдельной коллекции.
Смещение к началу координат сохраняется при изменении набора элементов.

«Сохранять инстансы» создаёт обычные Mesh-объекты Blender с общими данными
геометрии, как связанные дубликаты Alt+D. Выбирайте окно прямо на фасаде и
редактируйте в Edit Mode: изменятся все объекты с тем же мешем. Положение,
поворот и масштаб каждого экземпляра остаются независимыми. Для самостоятельной
правки одного экземпляра сделайте его меш однопользовательским средствами Blender.
Снятая галка создаёт независимые меши и требует больше памяти. Разные варианты
геометрии или материалов могут иметь отдельные меши даже у одного типа Revit.
Отдельные скрытые объекты-прототипы и пустышки-размещения больше не нужны.

При уменьшении выбранного набора и неизменных исходнике/настройках аддон удаляет
только исключённые размещения. Оставшиеся объекты сохраняют свои имена и ID,
Revit и конвертация не запускаются. При полном обновлении собственные имена
восстанавливаются без накапливания .001. Имена чужих объектов не меняются.
«Настройки → Перевыгрузить из Revit» принудительно обновляет геометрию и материалы.
После перехода со старой0.2.0 первый полный импорт записывает метаданные,
необходимые для безопасного быстрого применения следующего выбора.

Материалы переносятся как базовые PBR-материалы, доступны UV, цвета, прозрачность,
шероховатость и найденная базовая текстура. Полное совпадение с рендерером Revit
не гарантируется. Отсутствующие исходные текстуры восстановить нельзя. При включённой
упаковке найденные изображения сохраняются внутри `.blend` после обычного сохранения
сцены пользователем. Аддон сам не сохраняет `.blend` и Preferences.

## Ограничения и диагностика

Комплект содержит отдельные обработчики Revit 2024, 2025, 2026 и 2027, включая
варианты .NET 10 для обновлений 2025.5/2026.5. Аддон читает фактическую версию
Revit.exe. Нельзя просто переименовать папку Revit или подставить DLL другого года.
Revit LT не поддерживается. Будущие версии Revit требуют обновления аддона.
Проверка полного импорта выполнена на Revit 2027. Для 2024–2026 проверяются
компиляция с API соответствующего года и общая логика; полный импорт в этих
версиях в среде разработки пока не запускался. Выгружается основной локальный документ; геометрия
связанных RVT пока не включается. Сложные RPC-объекты и элементы без экспортируемой
геометрии отражаются в предупреждениях. Для выбранных групп/семейств переносится
принадлежащая им геометрия, поэтому составной элемент может включать вложенные части.

Кнопка «Отчёт» в панели Blender открывает список предупреждений и полный текст
выбранной строки. Дополнительные подробности находятся в рабочей папке:
каталог, `warnings.json`, `manifest.json`, `worker.log`, `status.json`, `conversion.log`. Не отправляйте
целиком папку задания посторонним: она содержит копию проекта и локальные пути.
После закрытия обработчика ненужные папки завершённых заданий можно удалить вручную.
«Отменить» завершает только процесс, запущенный этим аддоном; предыдущий импорт
сохраняется. Одновременно выполняется одно задание на экземпляр Blender.

Автор и бренд: XIVgate. Публичная лицензия проекта не объявлена.


## Дополнения раннего доступа 0.3.1

В 0.3.0 остаются стабильные функции и выбор релизов. Канал «Ранний доступ»
предлагает 0.3.1 отдельно; вернуть 0.3.0 можно тем же списком.

Галки теперь применяют разницу. Уже загруженные элементы временно убираются из
сцены в локальное хранилище, а при обратном включении возвращаются те же объекты
с теми же мешами, именами и пользовательскими правками. По-настоящему новые ID
выгружаются отдельно и добавляются к модели, без замены остальных объектов.
Одинаковые меши и материалы присоединяются к существующим по точной сигнатуре.
Для составных семейств, групп и зависимых частей, где изменение выбора меняет
оставшуюся геометрию, плагин безопасно переходит к полной выгрузке.
Временно убранные объекты продолжают занимать память; полная перевыгрузка
пересоздаёт набор и убирает старое хранилище. Не очищайте его вручную, если хотите
возвращать выключенные элементы без Revit.

«Типы» группирует по семейству/типу внутри категории. Поиск ищет также имя типа,
семейство и ID. Чтобы найти пропавшую деталь, выберите предполагаемую категорию
или тип, включите «Границы только исключённых» и нажмите «Границы». Это лёгкие
каркасы до 1000 элементов без загрузки их геометрии. В режиме «Объекты» показывается
один выбранный элемент списка. «Убрать» очищает только наш предпросмотр. Затем
отметьте нужный тип/объект и примените импорт. Границы из старого каталога 0.2.0
недоступны — сначала один раз получите новый список. Отсутствующий bounding box
не означает, что элемент удалён; он может быть служебным или не иметь геометрии.
Причину конкретной пропажи по одному скриншоту автоматически определить нельзя.

Проверенный кэш выгрузки можно использовать после закрытия рабочего Revit.
Проверяются исходный RVT, его расположение, состав, детализация, обработчик,
геометрия, материалы и доступные исходные bitmap-файлы. Неизвестные внешние
зависимости, отсутствующие карты и связанные файлы отключают такое повторное
использование. Изменённые/повреждённые данные вызывают новую выгрузку.
Изменение галок применяет состав к текущей модели; для принудительного перечитывания
источника и обновления текстур используйте «Перевыгрузить из Revit».

«Очистить завершённые задания» показывает путь, количество и размер до удаления.
Активные, незавершённые, чужие каталоги и задания с файлами, используемыми текущими
сценами Blender, сохраняются. Непакованные текстуры защищаются от очистки.
Ссылки из других, сейчас закрытых .blend проверить нельзя: перед очисткой общего
кэша сохраните такие сцены с упакованными текстурами либо храните их данные отдельно.
