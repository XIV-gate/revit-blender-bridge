# AGR Revit Bridge 0.4.7 — ранний доступ

Автор и бренд: XIVgate. Локальный импорт RVT из Blender. Нужны Windows,
установленный активированный Revit 2024–2027 и Blender 4.2 или новее.
Проверены Blender 4.2.14 и 5.2.3. Отдельные Python, Dynamo и Houdini не нужны.

## Установка и первый импорт

1. Скачайте `agr_revit_bridge-0.4.7.zip` из релиза раннего доступа GitHub.
   Blender → Preferences → Add-ons → Install from Disk; установите ZIP целиком
   и включите AGR Revit Bridge. Панель: 3D View → N → AGR.
2. Сохраните .blend, укажите RVT. Путь Revit.exe находится в «Настройки → Подключение Revit»:
   можно указать вручную или нажать «Найти и выбрать версию Revit».
   Список содержит версии и полные пути. При нескольких установках запускается
   только выбранная. Более новую модель старый Revit открыть не может.
3. Нажмите «Получить список». При первом подключении плагин покажет путь .addin
   и папку задания. Работает отдельный процесс Revit с копией RVT.
   Обновление модели происходит в копии; оригинальный файл не перезаписывается.
4. Проверьте выбор в каталоге, затем нажмите «Импортировать выбранное».
   После изменения галочек нажмите «Обновить импорт».

Автопоиск проверяет стандартные папки Autodesk и значения InstallationLocation,
InstallLocation, InstallDir в регистрационных ключах Autodesk Revit Windows.
Исполняемые файлы проверяются по реальной версии; дубликаты объединяются.
Незарегистрированную нестандартную установку укажите вручную.

## Категории и элементы

Используется один список-дерево. Стрелка слева от категории раскрывает входящие
в неё элементы; повторное нажатие сворачивает их. Галочка категории меняет всю
категорию, галочка дочерней строки — только этот элемент. Минус означает
частичный выбор; число рядом показывает выбранные/все элементы категории.

Название элемента показывает тип и причину рекомендации при наведении; нажатие
открывает полные свойства, ID и рабочий набор. Предположение о внутренней стене
по имени типа остаётся только рекомендацией: вы можете отметить её вручную.
Смена строки больше не раскрывает блоки пояснений и не перестраивает панель.

Поиск работает по названиям элементов, категориям, типам, семействам, рабочим
наборам и ID. Подходящие категории раскрываются. Поиск не меняет выбор импорта.
«Все», «Ничего», «Рекомендуемые» под деревом относятся ко всей модели.
Превью рамок включается справа от строки категории или отдельного элемента.

## Обновление состава и инстансы

Уже загруженные элементы при снятии галочек временно убираются из сцены в
локальное хранилище. Повторное включение возвращает те же объекты и Mesh:
сохраняются имена, размещения и правки. Хранилище продолжает занимать память.
Новые ID по возможности выгружаются отдельно и присоединяются без замены старых.
Для составных и зависимых элементов, где это небезопасно, выполняется полная
выгрузка. Изменение исходника/параметров также может потребовать полное обновление.

«Сохранять инстансы» создаёт обычные Mesh-объекты с общими данными, как Alt+D.
Выделите окно на фасаде и редактируйте в Edit Mode: изменятся экземпляры с тем
же Mesh. Положение, поворот и масштаб остаются независимыми. Для правки только
одного экземпляра сделайте его Mesh однопользовательским в Blender.

Объекты и Mesh названы по категории, семейству, типу и ID/варианту. Длинные имена
могут сокращаться под ограничение Blender; исходные данные остаются в Custom
Properties. Кнопка «Обновить имена объектов и мешей» исправляет старые служебные
имена без Revit. Пользовательские имена и чужие общие данные сохраняются.

«Настройки → Перевыгрузить из Revit» перечитывает источник целиком. При таком
обновлении геометрия пересоздаётся: изменения импортированных Mesh могут быть
заменены. Пользовательские объекты сохраняются; для самостоятельной геометрии
используйте свою коллекцию. Аддон сам не сохраняет .blend или Preferences.

## Превью каждого слоя

Справа от каждой строки категории, рабочего набора, типа и объекта находится
кнопка превью рамок. Нажмите её: плагин покажет габариты именно этого слоя и
приблизит вид к ним. Повторное нажатие выключает рамки этого слоя. Можно включить
несколько слоёв одновременно; включённая кнопка подсвечена значком глаза.

Не нужно предварительно выделять строку, менять галочки или импортировать модель.
Превью не меняет выбор для импорта и не загружает сетки из Revit. Общие кнопки
«Границы/Убрать» и фильтр исключённых больше не нужны. Показывается весь слой,
без скрытого ограничения первыми 1000 элементами. После импорта рамки совмещаются
с моделью, в том числе при другом смещении координат и перемещённом корневом объекте.

Если в старом каталоге нет габаритов, плагин предлагает получить список заново.
Некоторые служебные элементы не имеют габаритов — это не доказательство пропажи.

## Материалы, отчёт и рабочая папка

Переносятся базовые PBR-материалы, UV, цвета, прозрачность, шероховатость и
найденные изображения. Полное совпадение с рендерером Revit не гарантируется.
Отсутствующие в исходниках текстуры восстановить нельзя. При включённой упаковке
изображения встраиваются в .blend после обычного сохранения сцены пользователем.

«Отчёт» показывает предупреждения и сводную информацию. Все выбранные элементы
без отдельной видимой геометрии объединены в одну информационную запись с
количеством. Причинами могут быть фаза, вариант, составной элемент или связь.
«Копировать подробности» сохраняет доступ к исходным сообщениям и ID.

Кэш по умолчанию: рядом с сохранённым .blend, Data/Cache/RevitBridge.
Для несохранённой сцены задайте рабочую папку в «Настройках». В заданиях находятся
копия RVT, геометрия, текстуры и журналы. Не передавайте всю папку посторонним.
Проверенный кэш учитывает исходник, параметры, файлы выгрузки и доступные bitmap.
Неизвестные зависимости, отсутствующие карты и связанные файлы могут отключить
его повторное использование. Повреждённый или устаревший кэш вызывает выгрузку.

«Очистить завершённые задания» сначала показывает путь, количество и объём.
Активные, незавершённые, чужие задания и файлы, используемые текущими сценами,
защищены. Ссылки из закрытых .blend проверить нельзя: перед очисткой общего кэша
упакуйте текстуры таких сцен либо храните их данные отдельно.

## Revit и запрос доверия

Наша DLL пока не подписана сертификатом издателя. При доверии к источнику
пользователь может выбрать «Всегда загружать». «Загрузить один раз» действует
на один запуск и повторяет запрос позже. По Autodesk решение связано с файлом,
расположением и ID надстройки; новая версия в другой папке может спросить снова.
Аддон не подтверждает диалог и не меняет доверенных издателей.

Справка Autodesk:
https://help.autodesk.com/cloudhelp/2022/ENU/Revit-Troubleshooting/files/GUID-36D29367-A540-4CFD-9773-4995BF1DF08A.htm

Обычные предупреждения модели в рабочей копии обрабатываются автоматически;
неизвестные вопросы, лицензия и доверие требуют ответа пользователя.
«Показать Revit» показывает только рабочий процесс плагина.
«Отменить» останавливает его задание; предыдущий результат сохраняется.

## Обновления и совместимость

«Получить версии» → нужный канал → нужная версия → «Установить».
Можно выбрать предыдущую версию. Проверяются SHA256 ZIP и файлы комплекта.
При ошибке установки выполняется откат. Если старый обновитель уже заблокирован
ошибкой прежней DLL, один раз установите новый ZIP через Install from Disk.
Регистрация восстанавливается самим аддоном; вручную править .addin не нужно.

0.4.0 объединяет все текущие функции в одной стабильной сборке. Исправления
0.4.1, 0.4.2 и далее выходят в раннем доступе. После проверки и доводки выпускается
следующая стабильная 0.5.0.
Старые тестовые релизы остаются историей, а не обязательными промежуточными шагами.

В комплекте шесть вариантов обработчика: 2024 (.NET Framework 4.8), 2025/2026
(.NET 8 и .NET 10 для обновлений .5), 2027 (.NET 10). Revit LT не поддерживается.
Полный импорт реальной модели ранее проверен на Revit 2027. Для 2024–2026
проверены компиляция с API соответствующего года и общая логика, но не полный
импорт. Геометрия связанных RVT пока не включается. Сложные RPC и отсутствующие
исходные текстуры остаются ограничениями. Проект публичен, лицензия не объявлена.


## Группы настроек в 0.4.1

В основной панели остаются файл RVT, список элементов и действия импорта.
Раскройте «Настройки»:

- **Подключение Revit**: ручной путь к программе, «Автопоиск Revit» для выбора
  установленной версии, «Подключить Revit» для регистрации обработчика.
  При работающем процессе здесь доступно его закрытие.
- **Настройки импорта**: инстансы, материалы, доступные текстуры, упаковка
  изображений, координаты, детализация и полная перевыгрузка из Revit.
- **Рабочие данные**: рабочая папка, проверенный кэш и очистка завершённых заданий.

Каталог регистрации надстройки определяется автоматически и больше не показывается
как пользовательская настройка. Он отличается от каталога программы Revit.exe.
Это изменение интерфейса; сохранённые значения параметров импорта не сбрасываются.
Выбирайте «Ранний доступ → 0.4.7» для установки этой версии. Стабильная 0.4.0
остаётся отдельной, неизменённой сборкой.


## Автоматическая рабочая папка

Пустое поле «Своя папка» означает автоматический режим: Data/Cache/RevitBridge
рядом с текущим сохранённым .blend. В аддоне нет фиксированного пути к Desktop
или имени пользователя. Если .blend сохранён на рабочем столе, автоматический
кэш окажется рядом с ним. Для другого расположения укажите собственную папку.
Путь не разбивается на строки по пробелам; в панели отображается короткий режим.


## Единый центр превью и модели (0.4.3)

«Разместить около начала координат» использует одно смещение XY для рамок и
геометрии; исходные высоты сохраняются одинаково. До первого импорта центр
выбирается по выбранной геометрии, а служебные точки/категории не смещают его.
После первого превью этот центр сохраняется и передаётся конвертации, поэтому
рамки и импортированная модель не расходятся. Если модель уже импортирована
с центрированием, используется её смещение. При переключении галочки существующие
рамки обновляются сразу; геометрия применяется кнопкой обновления импорта.

При обновлении аддона старые превью выравниваются повторно. Ручное перемещение
корневого объекта модели учитывается. Неизменённые исходные координаты доступны
при выключенном центрировании.

## UV и карты рельефа

UV из выгрузки Revit проходят через USD в слой `st` меша Blender. Поддерживаемые цветовые карты и активные height-карты используют этот слой. Галочка «Переносить доступные текстуры» управляет подключением изображений, а «Упаковать текстуры в .blend» — их встраиванием в сохранённый файл.

В 0.4.3 исправлено подключение активных поддерживаемых height-карт к Bump. Цветовая карта и уже подключённый Normal не заменяются. Сила карты переносится из явного относительного параметра Revit; физическая глубина не угадывается, Distance остаётся стандартным Blender. Неизвестные явные режимы карт пропускаются с причиной `revit:height_skip_reason` в свойствах материала.

Для старого импорта исправленный материал появится после полной пересборки: «Настройки → Настройки импорта → Перевыгрузить из Revit» и обновление импорта. Сначала сохраните отдельную копию сцены, если вручную меняли импортированную геометрию: полная пересборка заменяет её. Обычное снятие и восстановление галочек не пересоздаёт материалы ради обновления аддона.

## Если операция завершилась ошибкой

В 0.4.4 ошибка остаётся в отчёте, а не только во всплывающем сообщении.
Откройте «Отчёт», выберите «Ошибка операции» и скопируйте подробности существующей
кнопкой. В папке активного задания также сохраняется blender_error_*.json.
Передавайте диагностику лично: в тексте могут быть локальные пути и имена файлов.

«Показать Revit» раскрывает главное окно своего процесса и уже видимый активный
диалог, не открывая скрытые служебные окна. Документ, открытый через API, может
не показываться в обычном окне; процесс остаётся запущенным для следующих операций.

## Экспорт логов (0.4.5)

Нажмите «Экспорт логов» под отчётом и выберите путь ZIP. В summary.txt находится
сводка версий, состояния, времени этапов, RAM и VRAM; подробности и журналы —
в остальных файлах архива. Можно экспортировать во время обработки, пока
интерфейс Blender отвечает. Паузы после готовности не считаются временем обработки.

RAM измеряется на переходах между этапами; VRAM — в момент экспорта через
драйвер NVIDIA. Если свободная VRAM недоступна, показано «нет данных».
RVT, геометрия и текстуры не включаются. В логах могут быть пути и имена файлов:
отправляйте архив разработчику лично. Уже существующий ZIP не перезаписывается.

## Рабочие модели и шаблоны видов (0.4.7)

Если связи не запрашиваются, рабочая модель сначала открывается в отдельной
отсоединённой копии с закрытыми рабочими наборами. Аддон отключает Revit-ссылки,
сохраняет подготовленную копию внутри папки задания и открывает её со всеми
рабочими наборами для каталога и экспорта. Исходный RVT не перезаписывается.
Это избегает серверного ожидания в TransmissionData на проверенных моделях.
Относительные внешние ссылки, кроме RVT, перечисляются в отчёте. Их пути здесь
автоматически не переназначаются: проверьте соответствующую геометрию, если
используете связанные CAD-файлы. Самостоятельно перезагружать их аддон не будет.

Подготовленные RVT и логи удаляются вместе с завершённым заданием при очистке
кэша. Первое обновление старого формата Revit может занимать минуты. Повторная
выгрузка в уже открытом рабочем процессе не требует нового обновления формата.

Собственный временный 3D-вид не наследует управляющий шаблон проекта: он может
блокировать смену детализации. Существующие виды и шаблоны сохраняются.
