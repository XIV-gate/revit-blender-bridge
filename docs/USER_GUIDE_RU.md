# XIVgate Revit Bridge 0.1.0

Локальный импорт выбранной геометрии RVT из панели Blender. Dynamo и Python
отдельно устанавливать не нужно. На компьютере должны быть Windows и установленный,
работающий Revit 2027. Первая версия проверяется с Blender 4.2 LTS и 5.2 LTS.
Файл более новой версии Revit открыть в старой версии Revit нельзя.

## Установка и первый запуск

1. В Blender откройте Preferences → Add-ons → меню → Install from Disk и выберите
   ZIP `xivgate_revit_bridge-0.1.0.zip` целиком. Включите XIVgate Revit Bridge.
2. В 3D View нажмите N, откройте вкладку XIVgate, панель Revit → Blender.
3. Укажите файл RVT, Revit.exe версии 2027 и рабочую папку с достаточным местом
   для копии RVT, геометрии и журналов.
4. Нажмите «Подключить Revit». Окно покажет точный путь создаваемого файла
   регистрации `.addin`; подтвердите его создание. Этот шаг нужен один раз.
   Файл указывает на обработчик внутри установленного аддона: не перемещайте
   установленную папку после подключения. При удалении аддона удалите также
   именно этот файл регистрации. Иная существующая регистрация не заменяется
   автоматически; старое подключение требуется удалить вручную перед новым.
5. Нажмите «Получить список». Запустится отдельный Revit, который прочитает копию.
   Первый запуск и обновление старого RVT могут занять несколько минут.

В Revit не требуется вручную создавать 3D-вид или граф Dynamo. Сам Revit всё равно
необходим: формат RVT обрабатывается через его API. При первом подключении Revit
может спросить о загрузке локального дополнения. Если требуется ответ на диалог,
панель сообщит об этом: нажмите «Показать Revit», проверьте вопрос и ответьте вручную.
Обычные предупреждения документа при открытии рабочей копии принимаются автоматически
и записываются в отчёт. Предупреждения API также сохраняются в отчёт без ручного
подтверждения. Ошибки не исправляются удалением элементов: обработчик пытается
безопасно откатить операцию и сообщает причину остановки. Неизвестные диалоги,
лицензирование и настройки приватности автоматически не подтверждаются.
Обычное окно обновления 2024 → 2027 — индикатор процесса.
Обновлённая рабочая модель не сохраняется поверх исходника и не синхронизируется.

## Выбор и повторный импорт

Список можно показать по категориям, рабочим наборам или отдельным объектам.
Число справа от группы — выбранные / все элементы. Галка группы меняет все её
элементы; частично выбранная группа показывает неполное число без общей галки.
Поиск фильтрует отображение, но не меняет выбор. Кнопки «Все», «Ничего» и
«Рекомендуемые» действуют на весь каталог, включая скрытые поиском строки.

Предварительно выбираются вероятные фасадные и спорные элементы. Мебель, инженерные
системы и явно внутренние элементы обычно исключены. Это подсказка, а не точное
геометрическое распознавание оболочки. В реальных проектах наружная стена может
быть помечена как внутренняя: проверьте рабочие наборы, спорные строки и причину
рекомендации в режиме «Объекты». Итоговый экспорт следует вашим галкам.

Нажмите «Импортировать выбранное». Измените галки и нажмите «Обновить импорт» для
замены предыдущего результата этого импорта. Новая ревизия сначала проверяется,
затем заменяет предыдущую. Посторонние объекты не удаляются; пользовательские
объекты внутри старой коллекции сохраняются. Изменения самой импортированной
геометрии при обновлении заменяются. Для ручного моделирования делайте отдельные копии.
Смещение к началу координат сохраняется при изменении набора элементов.

«Сохранять инстансы» создаёт общие прототипы и размещения коллекций Blender.
Одинаковая геометрия вместе с материалами хранится один раз. Число размещений
может оставаться большим — инстансы уменьшают дублирование мешей, а не количество
элементов здания. Снятая галка создаёт независимые меши и требует больше памяти.

Материалы переносятся как базовые PBR-материалы, доступны UV, цвета, прозрачность,
шероховатость и найденная базовая текстура. Полное совпадение с рендерером Revit
не гарантируется. Отсутствующие исходные текстуры восстановить нельзя. При включённой
упаковке найденные изображения сохраняются внутри `.blend` после обычного сохранения
сцены пользователем. Аддон сам не сохраняет `.blend` и Preferences.

## Ограничения и диагностика

Первая версия содержит обработчик только Revit 2027. Другие версии Revit требуют
отдельной сборки и проверки. Выгружается основной локальный документ; геометрия
связанных RVT пока не включается. Сложные RPC-объекты и элементы без экспортируемой
геометрии отражаются в предупреждениях. Для выбранных групп/семейств переносится
принадлежащая им геометрия, поэтому составной элемент может включать вложенные части.

Кнопка «Отчёт» в панели Blender открывает список предупреждений и полный текст
выбранной строки. Дополнительные подробности находятся в рабочей папке:
каталог, `warnings.json`, `manifest.json`, `worker.log`, `status.json`, `conversion.log`. Не отправляйте
целиком папку задания посторонним: она содержит копию проекта и локальные пути.
После закрытия обработчика ненужные папки завершённых заданий можно удалить вручную.
«Отменить» завершает только процесс, запущенный этим аддоном; предыдущий импорт
сохраняется. Одновременно выполняется одно задание на экземпляр Blender.

Автор и бренд: XIVgate. Приватная тестовая версия; публичная лицензия не объявлена.
