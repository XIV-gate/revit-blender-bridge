# AGR Revit Bridge 0.5.5 — ранний доступ

- Четыре независимые настройки: перезапись исходного RVT, поиск подготовленной
  копии, сохранение временных данных и упаковка текстур в .blend. Перезапись
  по умолчанию выключена; остальные три настройки включены.
- Модель владеет своей `<имя>.Data` рядом с RVT. Импорт доступен из несохранённой
  Blender-сцены и разных .blend; для общей рабочей папки RVT разделены по имени.
- Поиск копии намеренно допускает старое содержимое того же исходника. Проверяются
  привязка к модели, точный build Revit и целостность RVT. Дата подготовки и отличие
  исходника показаны в панели. Без поиска выполняется свежая подготовка.
- При перезаписи подготовленная копия атомарно заменяет оригинал, в том числе
  старая найденная копия. Это явно указано в панели и подсказке. Занятый или
  изменившийся во время подготовки исходник не заменяется. Общие модели становятся
  самостоятельными локальными снимками; это не синхронизация с BIM-центральной.
- Очистка происходит после успешного импорта и подтверждённого штатного выхода
  Revit. Нужные неупакованные текстуры остаются в `textures`, пути Blender обновляются.
  На ошибке или аварийном завершении сохраняются временные файлы и диагностика.
- Выбор установленной версии Revit вынесен рядом с выбором RVT; список содержит
  найденные версии и сборки. Ручной путь для нестандартных установок сохранён.
- Укорочены имена повторных конвертаций, чтобы не добавлять лишнюю длину Windows-путям.

Старые папки 0.5.4 не перемещаются автоматически. Стабильная версия остаётся 0.5.0;
0.5.5 публикуется как Early Access. Загрузчики ABI 1 не пересобираются.
