# AGR Revit Bridge 0.5.3 — ранний доступ

Исправлена остановка импорта на стартовом сообщении Revit о сбое
`Application Dynamo Player For Revit`.

Причина воспроизведённого случая: Dynamo Player выбирает порт 55000 для
локального HTTP-сервера, а Windows зарезервировала диапазон 54961–55060.
Попытка регистрации `http://localhost:55000/` возвращает Windows error 32;
после повторов Dynamo Player завершает OnStartup с `Server failed to start`.
Это происходит до открытия RVT и не связано с числом полигонов или инстансов.

Теперь служебный Revit автоматически закрывает именно этот необязательный
стартовый сбой и продолжает импорт через наш Revit API worker. Сбой сохраняется
в отчёте и журналах. Dynamo Player не требуется для импорта.

Обработка ограничена точным ID диалога и именем приложения, одним срабатыванием,
подтверждённым заданием сканирования и фазой до первой операции с документом.
Обычный пользовательский Revit, запросы доверия, лицензирования, восстановления
модели и ошибки других надстроек это правило не затрагивает. Резервирование
портов, файлы Dynamo и настройки Revit не изменяются.

Для других диалогов Blender теперь показывает «Ожидание ответа в Revit» вместо
полосы «Обработка модели».

Постоянные загрузчики ABI 1 сохранены без изменения. Обновлены все шесть
вариантов worker для Revit 2024–2027. Стабильной остаётся версия 0.5.0.

Проверено в настоящем Revit 2027: тот же сбой Dynamo Player закрыт автоматически,
каталог реальной модели из 19 531 элемента получен, 32 выбранных элемента
выгружены и импортированы в Blender 5.2. Исходный RVT не изменился.
Окончательная DLL дополнительно дважды прошла сканирование и экспорт небольшой
модели с тем же реальным сбоем Dynamo. Установка и интерфейс проверены в Blender
4.2/5.2, обновление 0.5.0 → 0.5.3 → 0.5.0 — в изолированном Blender 5.2.
Это проверка устранения блокировки запуска, а не замер полного импорта модели.
