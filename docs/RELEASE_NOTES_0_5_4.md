# AGR Revit Bridge 0.5.4 — ранний доступ

Исправляется подготовка старых общих моделей с недоступными ссылками Revit Server
и обработка двух дополнительных предупреждений при обновлении рабочей копии.

Найденная причина сетевой задержки: Revit разрешает сохранённые серверные ссылки
ещё при чтении TransmissionData и первом открытии документа. Закрытые рабочие
наборы и состояние Unloaded сами по себе не исключают эти обращения.

При выключенной загрузке связей аддон подготавливает только одноразовую копию:
серверные RVT-ссылки в её TransmissionData заменяются незагруженными локальными
ссылками. До и после записи проверяются имена и SHA-256 всех остальных потоков
RVT, записанные метаданные читаются повторно. После устранения серверных обращений
окончательную запись выполняет официальный Revit API; повторно проверяются состояния
связей и SHA-256 остальных потоков.
Оригинал не редактируется. Другие файлы и настройки сети не изменяются.

Это адаптер внутренней схемы метаданных Autodesk, а не документированная операция
Revit API. Разрешена только проверенная схема версии 5; неизвестная схема, ошибка
структуры или несовпадение контрольных сумм останавливают подготовку до открытия
рабочей копии. При включённой загрузке связей эта замена не выполняется.

В служебном Revit автоматически принимаются точные диалоги обновления аналитической
модели и отсутствующих сторонних updaters. Для последнего выбирается «Продолжить
работу с файлом», без отключения будущих предупреждений и сохранения оригинала.
Подтверждения ограничены фазой открытия рабочей копии, аутентифицированным заданием,
отсутствием неразрешённых ошибок Revit и четырьмя срабатываниями каждого ID. Действия записываются
в отчёт. Неизвестные диалоги, ошибки модели, доверие DLL и лицензирование требуют
отдельного решения.

При обновлении старого RVT панель отдельно сообщает о пересчёте модели средствами
Revit. Устранение сетевой задержки не устраняет стоимость преобразования модели
из старой версии: большой проект с множеством семейств может долго пересчитываться.
В проверяемом RVT сам Revit сообщил об автоматических изменениях некоторых
семейств при обновлении, включая удаление нестроящихся элементов и типов.
Эти предупреждения сохраняются в отчёте. Проверка SHA-256 относится к подготовке
ссылок до обновления; дальнейшие нативные изменения семейств нужно оценивать по отчёту.

Дополнительно исправлен воспроизведённый `Access denied` при атомарной записи
состояния: читатель JSON освобождает файл до разбора текста, а обе стороны обмена
выполняют ограниченные короткие повторы замены при временной блокировке Windows.
Постоянная блокировка остаётся ошибкой; прежний файл не обрезается и не удаляется.
Пустые события Revit FailuresProcessing больше не вызывают запись пустого отчёта
и строки журнала для каждой временной транзакции семейства.

Добавлен повторный кэш подготовленных RVT. После успешного открытия и сохранения
рабочей копии аддон сохраняет отдельную проверенную модель в `prepared_models`
внутри выбранной рабочей папки. Ключ включает SHA-256 исходника и точный build
Revit: изменённый исходник или другая версия Revit требуют новой подготовки.
При повторном запуске из кэша создаётся новая рабочая копия; кэш не открывается
для редактирования. Контрольные суммы проверяются перед использованием.
Кэш отключён при загрузке связей или внешних зависимостях геометрии, требующих
свежей подготовки. Кнопка очистки кэша удаляет и подготовленные модели.

Ускорена выборочная выгрузка: временный вид ограничивается выбранными элементами
и необходимыми контейнерами. Раньше даже небольшая выборка могла обходить всю
модель. Семейства, вложенные элементы, группы, сборки, витражи, лестницы и ограждения
проверены сравнением с прежней выгрузкой на 14 нативных сценариях. Исходный документ
после выгрузки остаётся без изменений.

Проверки на исходном RVT 2019 размером 1,135 ГБ подтвердили подготовку восьми
серверных ссылок, нативную запись и повторное чтение метаданных через Revit API.
Содержимое 11 остальных потоков (14 записей CFB с учётом каталогов) сохранилось.
Первое обновление большой модели заняло около 80 минут; получен каталог из
226 815 элементов. Затем восемь окон успешно выгружены и импортированы в
изолированных Blender 4.2 и 5.2 с сохранением размещений и общих mesh-данных.
Повторный запуск с исходным RVT 2019 использовал проверенный кэш: каталог
226 815 элементов получен за 54 с вместо повторного 80-минутного обновления;
выгрузка восьми окон прошла. Это время получения каталога, не полного импорта.
Проверка выборочная, не полный импорт всех 226 тысяч элементов.

Стабильной остаётся 0.5.0. Загрузчики ABI 1 не пересобираются.
