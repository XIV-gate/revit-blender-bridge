# AGR Revit Bridge 0.4.2 — ранний доступ

- Один список-дерево: категории раскрываются стрелкой и показывают свои элементы.
- Выбор всей категории или отдельного элемента непосредственно в строках; превью справа от строки.
- Поиск раскрывает подходящие категории и не меняет галочки.
- Убраны переключение отдельных меню и автоматически раскрывающиеся блоки пояснений. Высота списка фиксирована.
- Тип, рабочий набор, ID и причина рекомендации доступны по наведению/нажатию на название элемента.
- Убраны лишние подсказки и переносы пути по пробелам. Для автоматической рабочей папки показан режим «Авто: рядом с .blend».
- Восстановление дерева при загрузке сцены и обновлении аддона; linked-сцены не изменяются.

Пустая собственная папка означает Data/Cache/RevitBridge рядом с текущим .blend.
Путь пользователя не зашит в аддон. При сохранении .blend на Desktop автоматический
кэш также находится там; для другого расположения задайте свою папку.

Установка: «Получить версии» → «Ранний доступ» → 0.4.2 → «Установить».
Стабильная версия остаётся 0.4.0.

[Инструкция 0.4.2](https://github.com/XIV-gate/revit-blender-bridge/blob/v0.4.2/docs/USER_GUIDE_RU.md).
