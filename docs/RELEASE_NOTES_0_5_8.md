# AGR Revit Bridge 0.5.8 — ранний доступ

Исправлено подключение Revit после перехода между версиями Blender, например
с 5.2 на 5.3. При обычном действии «Получить список» аддон сам переносит свою
регистрацию на установленную в текущем Blender копию загрузчика. Отдельно
переподключать Revit или редактировать .addin не требуется.

Перенос разрешён только для собственного одинакового загрузчика в штатных
соседних папках версий Blender: проверяются регистрация XIVgate, путь, версия
Revit и SHA-256 DLL. Чужие, отсутствующие, изменённые DLL и ссылки отклоняются.
Запись транзакционная, с защитой от конкурирующей замены и откатом при ошибке.
Параллельно открытый Revit и оригинальные RVT не изменяются.

Сам Revit может снова запросить доверие при изменении пути загрузчика.
Это штатная проверка Revit; аддон не подтверждает её скрытно.

Обновление: «Получить версии» → «Ранний доступ» → 0.5.8 → «Установить».
Рекомендуется получить исправление до следующего обновления Blender.
Если старая 0.5.7 уже перенесена и её встроенное обновление блокируется старым
внешним указателем, старый код не может исправить себя новым кодом до установки:
доступна штатная установка ZIP 0.5.8 через Blender. После установки перенос
выполняется автоматически. Править .addin вручную не нужно.

Проверены 258 Python-тестов (один пропуск из-за прав ОС), миграция через обычную
кнопку сканирования, установка ZIP в изолированных Blender 4.2.14 и 5.3.0.
Все шесть обработчиков Revit пересобраны; геометрический алгоритм не менялся.
Стабильной остаётся 0.5.0. Замороженные загрузчики ABI 1 не пересобирались.
