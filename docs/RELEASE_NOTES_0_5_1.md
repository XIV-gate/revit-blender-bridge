# AGR Revit Bridge 0.5.1 — кандидат раннего доступа

- Исправлены пропущенные инстансы с разными локальными началами сетки.
  Сравнение координат нормализовано, размещение компенсируется; исходный прототип,
  нормали, материалы и текстурные UV сохраняются.
- У явно нетекстурных материалов неиспользуемые UV больше не мешают объединению.
  При неизвестном статусе материала и наличии текстур сравнение UV остаётся строгим.
- Сохранённая сцена 0.5.0 при обновлении импорта действительно пересчитывает инстансы,
  а не завершает операцию прежним быстрым применением галочек. Пригодная выгрузка
  используется повторно; открывать RVT заново для этих исправлений не требуется.
- Исправлены рекомендации для разделителей помещений, линий лестничных эскизов,
  ограничений, служебных линий ограждений и CAD-вставок с числовым суффиксом копии.
  Ручной выбор по уникальным ID сохраняется.

На проверенной выгрузке при прежнем допуске 0,1 мм: 26 432 размещения,
5 123 → 4 322 сетки. При 1 мм получается 3 987 сеток, при 5 мм — 3 864.
Это показатели конкретной модели, а не обещание одинаковых результатов на любом RVT.
Близкие размеры могут быть реальными различиями; увеличение допуска намеренно
упрощает такие варианты. Начальное значение остаётся 0,1 мм.

Изменения проверяются на копии выгрузки. Стабильная опубликованная версия — 0.5.0;
этот кандидат не заменяет её без отдельного выпуска.
