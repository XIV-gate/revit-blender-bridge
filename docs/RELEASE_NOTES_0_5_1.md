# AGR Revit Bridge 0.5.1 — локальный кандидат

Кандидат проверяется локально и пока не опубликован. Опубликованная стабильная
версия остаётся 0.5.0; приведённые результаты не заменяют проверку финального ZIP.

- Разные локальные начала сеток больше не мешают объединению: размещение
  компенсируется. У явно нетекстурных материалов неиспользуемые UV не блокируют
  инстансы; настоящие текстурные UV и неизвестный статус проверяются строго.
- Добавлено совместное использование сетки для подтверждённых вариантов одного
  типа, отличающихся переносом и положительным масштабом по локальным осям.
  Масштаб переносится в размещение объекта, сохраняя физические размеры.
  Материалы, нормали и необходимые UV проверяются; одного имени типа недостаточно.
- Контекст конвертации обновлён до 6. «Обновить импорт» пересчитывает группировку
  из пригодной проверенной исходной выгрузки, включая подходящую сохранённую
  выборку, без нового запуска Revit. Исходные варианты остаются в кэше.
- Исправлены рекомендации для разделителей помещений, линий лестничных эскизов,
  ограничений, служебных линий ограждений и CAD-копий с числовым суффиксом.
  Причины видны в каталоге, ручной выбор по ID сохраняется. Удалённость Mass
  сама по себе остаётся рекомендацией; скрытого запрета всей категории нет.
- Необязательная настройка «Убирать дальние части» убирает отдельные несвязанные
  фрагменты перекрытий вдали от здания. Она включена по умолчанию, работает
  с копией геометрии и не меняет RVT или исходную выгрузку. Выключение и повторное
  обновление из пригодного кэша восстанавливают фрагменты.

В текущей живой сцене проверены 26 400 объектов и 3 537 Mesh вместо исходных
5 123 при сохранённом прежнем допуске 5 мм и новой проверке масштаба.
Все 1 512 проверенных стеклянных панелей используют один Mesh, сохраняя свои
размеры через масштаб размещения. Это результат конкретной модели и настроек,
а не прогноз для любого RVT. Начальный допуск по-прежнему 0,1 мм.

32 дальних вспомогательных объекта/CAD/Mass убраны выбором элементов; их можно
включить обратно. Отдельно у перекрытия 5602806 фильтр дальних частей убрал
158 треугольников несвязанного фрагмента, оставив 1 006. Это разные механизмы:
галочки управляют целыми элементами, фильтр — частями выбранного перекрытия.

Свежая чистая Python-проверка: 215 тестов, один пропуск по привилегиям Windows.
Проверки кандидата в изолированных Blender продолжаются. Новая нативная проверка
Revit для этих Python-изменений не заявляется. Пересборка импорта может заменить
ручные правки Mesh: перед изменением настроек сохраните отдельную копию сцены.
