# AGR Revit Bridge 0.4.7 — ранний доступ

- Исправлена подготовка рабочих моделей с недоступными серверными ссылками. Перед чтением геометрии отдельная копия открывается отсоединённой, с закрытыми рабочими наборами. Ссылки отключаются через API документа; подготовленная копия сохраняется только внутри задания и повторно открывается со всеми рабочими наборами.
- Для этой копии не вызывается `TransmissionData.ReadTransmissionData`: на проверенной модели этот метод обращался к прежнему Revit Server даже после локального SaveAs и надолго блокировал обработку.
- Исправлена ошибка `Detail Level cannot be modified`: собственный временный 3D-вид отключает унаследованный шаблон перед настройкой детализации и видимости. Исходные виды и шаблоны не изменяются; временная транзакция откатывается.
- В панели и временной шкале логов различаются отсоединение, сохранение рабочей копии и подготовка ссылок.
- Относительные внешние ссылки, кроме RVT, перечисляются в отчёте: их перенос из отсоединённой копии требует проверки. Автоматическая перезагрузка таких файлов не выполняется.

На реальной проблемной модели Revit 2024 → Revit 2027 прочитаны 2962 элемента,
выгружены 1414 размещений / 890 прототипов / 32 912 треугольников. После открытия
сама выгрузка заняла около 3,5 с. Геометрия, UV и три найденных изображения
проверены в изолированных Blender 5.2.3 и 4.2.14. Контрольная сумма исходного RVT не изменилась.

Первое обновление старого RVT самим Revit может занимать несколько минут:
в этой проверке открытие/подготовка заняли около 4 мин. Это не обещание мгновенного
открытия любых файлов. Копии и логи находятся внутри кэша задания и удаляются
штатной очисткой после завершения, если не нужны активной сцене.

DLL остаются без цифровой подписи. Настройки доверия не меняются автоматически.
Полная проверка на настольных Revit 2024–2026 по-прежнему не выполнена.

Установка: «Получить версии» → «Ранний доступ» → 0.4.7 → «Установить».
Стабильная версия остаётся 0.4.0.
