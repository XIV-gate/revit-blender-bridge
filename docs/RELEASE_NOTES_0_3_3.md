# AGR Revit Bridge 0.3.3 — стабильная версия

- Исправлена регистрация после ручной переустановки ZIP и загрузка новой панели без старых модулей в памяти.
- Явный частичный выбор, причины исключений, просмотр и ручное включение элементов группы до импорта.
- Читаемые имена объектов и Mesh; существующие служебные имена можно исправить без повторного импорта.
- Элементы без отдельной геометрии объединены в одну информационную запись; исходные сообщения и ID сохранены.
- Подсказки для всех кнопок с указанием области действия выбора.
- Сохранены редактируемые связанные Mesh-инстансы и поддержка обработчиков Revit 2024–2027.

Проверки: обычные Python-тесты, изолированные Blender 4.2.14 и 5.2.3, сборка шести
вариантов обработчика. Полный импорт ранее проверен на Revit 2027; для 2024–2026
проверены компиляция с API соответствующего года и общая логика, но не полный импорт.
Экспериментальные delta-импорт, автоматический кэш и рамки не включены в стабильную сборку.

Установка: скачайте `agr_revit_bridge-0.3.3.zip`, установите через Blender
Preferences → Add-ons → Install from Disk. При работоспособном обновителе выберите
«Стабильные» → 0.3.3 → «Установить». При ошибке старого обновителя используйте ZIP
один раз: исправление сработает внутри новой установленной версии.

Нужен установленный активированный Revit; Revit LT не поддерживается.
Исходный RVT не перезаписывается. Недоступные исходные текстуры восстановить нельзя.
