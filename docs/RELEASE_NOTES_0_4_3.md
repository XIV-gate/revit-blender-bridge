# AGR Revit Bridge 0.4.3 — ранний доступ

- Превью границ и импорт используют одно смещение XY. Высоты сохраняются; удалённые служебные точки не определяют центр здания.
- Переключение «Разместить около начала координат» сразу переносит существующие превью. Ранее созданные рамки выравниваются при загрузке сцены и обновлении аддона.
- Активные поддерживаемые карты рельефа Revit подключаются к Bump в Blender, используют UV `st`, Non-Color и упаковываются вместе с остальными изображениями. Существующее подключение Normal не заменяется.
- UV сохраняются через выгрузку, USD и Mesh Blender. На реальной модели проверены 5203 меша; у 12 текстурированных прототипов координаты на всех трёх этапах совпали точно.

Относительная сила поддерживаемой height-карты переносится в Bump Strength; Distance остаётся стандартным Blender. Полное совпадение рендера Revit не гарантируется. Явные неподдерживаемые режимы карты пропускаются с причиной в свойствах материала.

Чтобы применить исправление рельефа к уже импортированным материалам, включите «Настройки → Настройки импорта → Перевыгрузить из Revit» и обновите импорт. Это полная пересборка импортированной геометрии: предварительно сохраните отдельную копию, если редактировали её вручную. При обычном обновлении локальные правки не сбрасываются ради нового материала.

Установка: «Получить версии» → «Ранний доступ» → 0.4.3 → «Установить».
Стабильная версия остаётся 0.4.0.
