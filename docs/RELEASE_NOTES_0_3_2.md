# AGR Revit Bridge 0.3.2 — Early Access

Исправление перехода со старых установок:

- Если собственный .addin остался, а DLL предыдущей версии уже удалена при
  переустановке ZIP, подключение автоматически заменяет устаревшую ссылку.
- Та же обработка действует при обновлении и возврате между релизами.
- Новая DLL обязана существовать. Чужие регистрации, внешние пути, ссылки,
  junction и неизвестные пути DLL не принимаются как собственная старая установка.
- После отключения и ручной установки ZIP новые UI и обновитель загружаются
  в том же процессе Blender; старые модули из памяти не используются повторно.

Друзьям можно передавать сразу ZIP 0.3.2. Установить через Install from Disk,
включить аддон и выполнить обычное подключение/получение списка. Ручная правка
файла .addin не нужна. Если обновитель 0.3.0/0.3.1 уже блокирует установку из-за
устаревшей регистрации, один раз установить ZIP 0.3.2 вручную: старый код
отказывает до загрузки исправления. При исправной регистрации переход через
встроенный список релизов работает.

Проверено на изолированных Blender 5.2.3 и 4.2.14: реальная установка старого ZIP,
воспроизведение ошибки, установка нового ZIP без перезапуска, новая панель,
восстановление регистрации и переход релиза со старой отсутствующей DLL.
92 обычных теста (один skip из-за недоступного создания Windows symlink).
Все шесть Revit worker пересобраны; в C# изменена только версия сборки.
Полный импорт в установленных Revit 2024–2026 по-прежнему не проверен здесь.

Все функции 0.3.1 сохранены. 0.3.0 остаётся стабильным каналом; эта версия —
ранний доступ. Опубликованные ZIP предыдущих версий не заменялись.
